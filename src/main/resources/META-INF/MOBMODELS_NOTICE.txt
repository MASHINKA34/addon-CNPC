Bundle update date: 2026-08-29

Texture behavior:
- Bundled mob models automatically use their matching base entity texture
  while the NPC still has the default Steve/Alex skin.
- A manually selected non-default NPC texture remains available as an override.
- Resource paths are normalized to lowercase for Minecraft 1.21.1.
- Textures stored by mods under both textures/entity and textures/entities
  are supported.

Bosses'Rise integration:
- Entity geometry is bundled from assets/block_factorys_bosses/geo/entity.
- The mod's nonstandard anim_bosses_rise/entity resources are exposed under
  the standard GeckoLib animations/entity path used by CNPC-Gecko-Addon.

Mowzie's Mobs integration:
- Bundled animated GeckoLib creatures: bluff, elokosa, sculptor, sol_visage,
  umvuthana, and umvuthi.
- Converted legacy Java creatures: Frostmaw, Ferrous Wroughtnaut, Foliaath,
  Baby Foliaath, Grottol, Naga, and Lantern. Their AdvancedModelRenderer
  geometry, UV layout, hierarchy, and MMModelAnimator keyframes were converted
  into standalone GeckoLib JSON. Each also includes portable idle and walk
  loops for use with Custom NPCs.
- The conversion is a resource adaptation only. No Mowzie's Mobs classes or
  runtime dependency are packaged in this archive.

2026-08-20 donor integration:
- All GeckoLib geometry, animation, and entity texture resources found in the
  seven listed donor archives are bundled under their original namespaces.
- Skarrier Mobs creatures implemented as generated Java ModelPart models were
  converted to standalone GeckoLib geometry. Their vanilla AnimationDefinition
  keyframes were converted as well; no Skarrier classes are packaged.
- Arda's Sculks fox and its vanilla fish/ghost render shapes, plus the Call from
  the Depths deep citizen, have portable GeckoLib geometry and idle/walk loops.
- Default model textures are selected through META-INF/MOBMODEL_TEXTURES.tsv.
- Selecting a model automatically selects its same-name animation file when it
  is available.
- The donor mods themselves are not bundled and are not runtime dependencies.

2026-08-20 second donor integration (addon 1.1.0):
- Added 271 selectable geometry files from the 19 donor projects listed above.
- Existing GeckoLib JSON geometry, author animation clips, and entity textures
  are kept under isolated resource namespaces.
- Java ModelPart and MCreator geometries were converted to standalone GeckoLib
  JSON. Authored AnimationDefinition clips are preserved where available;
  models driven only by runtime Java trigonometry include portable idle, walk,
  and attack loops suitable for Custom NPCs.
- Vanilla-rendered donor variants (infected mobs, piglins, moongus creatures,
  and similar entities) include standalone compatible geometry so the original
  donor mod is not needed at runtime.
- No donor classes, registries, world generation, AI, sounds, or mod metadata
  are packaged. This bundle provides visual NPC resources only.

2026-08-26 Dungeons and Combat integration:
- Added 48 standalone GeckoLib geometry files with paired animation files and
  reviewed default textures under the isolated dungeons_and_combat namespace.
- Preserved the donor's authored clips and supplied an idle alias to the two
  visual models whose animation files did not expose a clip named "idle".
- Imported only model, animation, and required texture resources. No donor
  classes, registries, data packs, sounds, or mod metadata are packaged.

2026-08-29 Apocalyptic Bosses integration:
- Added 39 standalone GeckoLib geometry files with paired animation files and
  reviewed default textures under the isolated panascraftrpgmod namespace.
- The models credited on the donor's project page to Toro Toro, Forrest and
  Painful, Baphomet's Guild, LittleRoom, EliteCreatures, Arts by Kev, Iplexity,
  Nocsy, Amonde, Pokmagoon's Workshop, tugkandeman, SamusDev, and ModelFoundry
  remain the property of those authors.
- Preserved the donor's authored clips and supplied an idle alias to the one
  model whose animation file did not expose a clip named "idle".
- Animation channels for hitboxes, capes, cloth, and spawned weapon or spell
  effects that the shipped geometry does not contain were removed, since those
  props only exist inside the donor mod at runtime.
- The donor's armor and projectile layer sheets were left out; only the mob
  textures its geometry actually uses are bundled.
- Imported only model, animation, and required texture resources. No donor
  classes, registries, data packs, sounds, or mod metadata are packaged.
