# Тема GUI: тёмный камень и аметист

Арт для контракта `prompts/97-art-gui-theme.md` и существующего `GeckoTheme` из промта 98.
Размеры текстур, UV и порядок иконок совпадают с Java-кодом. Java, локали, регистрации и
`mod_version=1.45.0` не изменялись.

## Сборка

Из корня репозитория, Python 3.10+ и Pillow (проверено с Python 3.13, Pillow 12.3):

```powershell
python scripts/generate_gui_theme.py
python scripts/generate_gui_theme.py --check
.\gradlew.bat build --console=plain
```

Пайплайн — разрешённый промтом фолбэк **Python + Pillow**, затем независимый экспорт
и проверка всех семи исходников через **Aseprite MCP**. Все линии и полигоны рисуются
целыми пикселями. Нет градиентов, сглаживания, фильтров, полупрозрачного свечения или
масштабирования рабочих текстур. Только диагностические превью увеличены nearest-neighbor.

Генератор — воспроизводимый источник рисунков: пересоздаёт семь `.aseprite`, семь PNG,
палитру, превью и `validation.json`. `--check` только читает и проверяет файлы.
Повторный запуск генератора перезаписывает ручные правки исходников. Если исходники
редактируются в Aseprite вручную, экспортировать их через Aseprite и перенести рисунок
в генератор до следующей полной пересборки.

Все исходники лежат рядом с этим README. В `icons.aseprite` 45 независимых видимых слоёв
`00_area` … `28_vent`, `48_phases` … `63_carrying`. Их cels сохраняются с локальными
координатами на общем холсте 256×256; palette chunk содержит палитру и акценты способностей.

## Экспорт и раскрой

PNG находятся в `src/main/resources/assets/cnpcgeckoaddon/textures/gui/theme/`.
Каждый PNG — RGBA8, альфа только 0 или 255.

| Файл | Размер | Раскрой |
| --- | --- | --- |
| panel.png | 64×64 | Рамка 8 px; середина `[8,56) × [8,56)` тайлится |
| button.png | 200×60 | Строки `[0,20)` обычная, `[20,40)` наведение, `[40,60)` выключена; рамка 4 px |
| toggle.png | 48×20 | `[0,24)` да; `[24,48)` нет; прозрачный фон для наложения на кнопку |
| field.png | 200×20 | Рамка 3 px; ровная тёмная середина |
| scroll.png | 16×48 | Дорожка, ползунок и стрелка вниз по 16 px; вертикальные концы по 2 px |
| header.png | 256×16 | Концы 8 px; середина `[8,248)` тайлится по X |
| icons.png | 256×256 | Ячейки 16×16, 16 в ряд; UV = `(i % 16 * 16, i // 16 * 16)` |

У панели одинаковые противоположные края центрального тайла. Рамка непрерывна на
стыках тайлов; кристальные вставки находятся внутри угловых 8px caps. Вариант панели
211×163 в превью проверяет также обрезанные последние тайлы. Кнопки имеют спокойную
середину, более яркий аметистовый край при наведении и нейтральный край при отключении.
Переключатель различается положением движка и знаками галочки/крестика, а не только цветом.

## Палитра

`gui_theme.gpl` — единая палитра из 16 цветов. Тёмные `#0A0A0A` и `#171717` взяты
из семейства `art/boss_bar_infernal/infernal_fire.gpl`. Аметистовые `#35224E`, `#4E316B`,
`#684189`, `#AF78CC`, `#BCA6EF`, `#D8C7FF` совпадают с
`art/aseprite/rift_crystal/amethyst.gpl`.

Свободно подобраны холодные оттенки камня `#161920`, `#1E222B`, `#252A35`, `#30303F`,
`#414052`, `#5D526D` и два приглушённых цвета переключателя `#64B69C`, `#A37E67`.
Это намеренный сдвиг оттенка от холодного камня к тёплым фиолетовым граням, а не линейное
осветление одного цвета. Палитра moss_cave использовалась как контекст проекта,
но её зелёные оттенки не переносились в фиолетовую тему.

У каждой иконки два тона темы (`#5D526D`, `#D8C7FF`), тёмная обводка `#0A0A0A`
толщиной 1 px и один акцент. Для способностей акцент читается из
`BossTelegraphUtil.ABILITY_COLORS`, для разделов — `#AF78CC`. Поэтому весь атлас
содержит 33 цвета; это предусмотренное контрактом исключение для акцентов способностей.
Отдельная иконка содержит не более четырёх непрозрачных цветов.

## Превью и проверки

- `preview/{panel,button,toggle,field,scroll,header}_4x.png`: каждый файл на тёмном и светлом фоне.
- `preview/icons_atlas_4x.png`: исходная UV-раскладка атласа на двух фонах.
- `preview/icons_4x.png`: 45 иконок с индексами и названиями; каждый рисунок увеличен ровно ×4.
- `preview/mockup_4x.png`: вручную составленный диагностический макет с тремя состояниями кнопки,
  полем, заголовком, переключателями и прокруткой. Это макет, не скриншот Minecraft.
- `preview/mockup_2x.png`, `preview/mockup_3x.png`: целочисленные масштабы GUI.
- `preview/panel_tiling_4x.png`: панель с несколькими полными и обрезанными тайлами.
- `validation.json`: размеры, цвета, SHA-256 текстур, занятость ячеек и контраст.

Проверено 26.09.2026:

1. Самопроверка прошла: RGBA8, точные размеры, альфа 0/255, палитра; panel/button/field
   содержат соответственно 14/13/13 цветов. Все 45 силуэтов уникальны, обводка не обрезана.
2. Aseprite MCP открыл исходники и экспортировал все семь PNG. Независимый экспорт
   совпал с поставляемыми текстурами пиксель в пиксель.
3. Повторная генерация дала побайтово одинаковые 28 файлов: исходники, палитру, PNG,
   превью и `validation.json`.
4. Макет и лист иконок визуально просмотрены. Минимальный расчётный контраст текста
   `#FFFFFF` — 12.96:1, `#D0D0D0` — 8.40:1 на областях текста панели, кнопок, поля и заголовка.
5. `gradlew build` прошёл, 1035 тестов, 0 ошибок, 0 падений, 0 пропусков.

**Игровая визуальная проверка не завершена.** Клиент запущен через `gradlew runClient`,
подготовлена отдельная копия мира `run/saves/GUI Theme QA`. Пользователь остановил
Computer Use клавишей Escape до получения скриншотов интерфейса. Дневных/ночных
скриншотов реального GUI в поставке нет; макеты не заменяют эту проверку.
Клиент после остановки автоматизации оставлен пользователю. Исходные настройки клиента
перед попыткой сохранены в `build/gui_theme/options.before.txt`; для проверки были
заданы `guiScale:3`, `overrideWidth:1280`, `overrideHeight:900` в локальном `run/options.txt`.

Оставшаяся приёмка в игре:

1. В тестовом мире открыть НПС палочкой, вкладку AI и меню босса/телепорта.
   Убедиться, что «Тема экранов» стоит на аддоне.
2. На дневном и ночном фоне проверить панель, поле и три состояния кнопок;
   получить скриншоты при GUI scale 2 и 3.
3. Открыть список фаз, способности и длинный список параметров: проверить иконки,
   прокрутку, границы тайлов и отсутствие искажения пикселей.
4. Проверить галочку/крестик и положение переключателя, читаемость `Да/Нет`, белого
   и серого текста. Итоговый статус «Проверено» на доске выставляет человек.

## Хранение в Git

Текстуры, исходники Aseprite, палитра, генератор, превью и `validation.json` входят
в репозиторий: они нужны для работы темы, её редактирования и воспроизводимой проверки.
Локальный клиент, тестовые миры и результаты Gradle остаются в игнорируемых `run/` и `build/`.
`implemented` на доске означает подготовленные ассеты и выполненные автоматические
проверки; недостающая игровая приёмка указана отдельно в evidence и заметке.
