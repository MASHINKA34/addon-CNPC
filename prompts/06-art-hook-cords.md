# Промт 06 (арт) — пиксель-арт текстуры шнуров хука: лиана, адские цепи, щупальце, призрак

## Роль

Ты — пиксель-арт художник и тех-артист для мода Minecraft 1.21.1
(`D:\GEYDEV\addon-CNPC`, аддон CustomNPCs + GeckoLib). Рисуешь текстуры **в стиле
ванильного Minecraft**, работаешь в **Aseprite** (CLI + Lua-скрипты), результат кладёшь
в репозиторий вместе с исходниками и скриптом сборки, чтобы арт можно было пересобрать
одной командой.

Код, который будет эти текстуры рисовать в мире, делает другой агент (промт 05).
Контракт ниже — общий, его нельзя менять в одностороннем порядке.

## Что рисуем

Босс кидает в игрока «хук» и тянет его к себе. Между боссом и жертвой всё время рывка
натянут шнур. Нужны **четыре стиля** этого шнура плюс наконечник к каждому:

| id | что это | ширина шнура в мире |
|---|---|---|
| `vine` | живая плетёная лиана: жгут из стеблей, мелкие листья, шипы | 0.25 блока |
| `chain_infernal` | адская цепь: тёмные железные звенья, раскалённые докрасна щели | 0.22 блока |
| `tentacle` | мясистое щупальце с присосками, живое и влажное | 0.35 блока |
| `ghost` | призрачная цепь: полупрозрачные звенья из холодного света, дымка | 0.28 блока |

## Технический контракт (жёсткий)

```
src/main/resources/assets/cnpcgeckoaddon/textures/entity/hook/<id>/cord.png   16 × 64  RGBA8
src/main/resources/assets/cnpcgeckoaddon/textures/entity/hook/<id>/head.png   16 × 64  RGBA8
<id> ∈ { vine, chain_infernal, tentacle, ghost }
```

- Каждый файл — **вертикальный filmstrip из 4 кадров** по 16×16. Кадр 0 сверху, кадр 3 снизу.
- `cord.png`: кадр — это **один сегмент шнура**, который движок ставит встык друг на друга
  вдоль всей длины. Значит нижняя строка пикселей кадра обязана **бесшовно стыковаться**
  с его же верхней строкой. Проверяется склейкой 8 копий кадра подряд.
- `head.png`: наконечник (крюк / коготь / кончик щупальца), «остриё» смотрит **вниз**,
  рисуется один раз у конца со стороны жертвы. Тоже 4 кадра.
- 4 кадра = зацикленная анимация. Циклится по кругу (кадр 3 → кадр 0 без рывка).
- Никакого другого размера, никакой горизонтальной раскладки, никаких `.mcmeta`:
  анимацию проигрывает код по номеру кадра.
- Формат: PNG, RGBA8, без интерлейса, без цветового профиля, без лишних чанков.

### Про плотность деталей

16 px ширины растягиваются на 0.22–0.35 блока, то есть текстура плотнее ванильной
(16 px на блок) в разы. Чтобы шнур не выглядел «чужим» рядом с блоками, рисуй **крупно**:
минимальный осмысленный элемент — кластер 2×2 пикселя, силуэт строится штрихами не тоньше
2 px, оттенков на стиль немного. Если на тесте шнур выглядит слишком дробным —
**упрощай рисунок**, размер текстуры менять нельзя.

## Правила пиксель-арта (обязательны)

- Только пиксель-перфект: карандаш 1 px, никаких мягких кистей, размытий, градиентных
  заливок, сглаживания, любых фильтров и апскейлов.
- Палитра ограничена: 8–14 цветов на стиль, сохраняется в `.gpl` рядом с исходником.
- Тени и света — со **сдвигом оттенка** (тени холоднее и насыщеннее, света теплее), а не
  осветлением/затемнением одного цвета.
- Контур — не чистый чёрный: тёмный вариант собственного цвета. Чистый `#000000` только
  если он осмысленно нужен (например, провал между звеньями цепи).
- Дизеринг — только вручную и только там, где он читается; на 16 px его почти не должно быть.
- Силуэт важнее деталей: шнур должен читаться с 20–40 блоков на фоне тёмного данжа
  **и** на фоне яркого неба. Проверить оба фона.
- Альфа: полностью прозрачный фон вокруг шнура. Полупрозрачные пиксели допустимы только
  у `ghost` (и лёгкая дымка), у остальных — либо 0, либо 255.

## Брифы по стилям

### `vine` — травяной
Жгут из 2–3 перекрученных стеблей. База — приглушённая листовая зелень с уходом в жёлтый
на свету и в сине-зелёный в тени; редкие бурые сухие волокна. По бокам изредка выступают
маленькие листья и короткие шипы (не в каждом кадре, чтобы при повторе сегментов не
получился «полосатый» узор). Анимация: медленное покачивание/скручивание, будто лиана
живая — сдвиг светового блика на 1 px по кадрам.
`head.png`: колючий крючок из одревесневшего побега, 2–3 шипа.

### `chain_infernal` — адские цепи
Звенья тёмного, почти чёрно-серого железа, овальные, чередование горизонтальных и
вертикальных звеньев (как ванильная chain, но толще и грубее). Внутри металла — трещины
раскалённого оранжево-красного, ближе к белому в самой горячей точке. Анимация: пульс
жара по трещинам (яркость и длина трещины гуляют по 4 кадрам), металл при этом статичен.
`head.png`: массивный зазубренный крюк с раскалённым остриём.

### `tentacle` — щупальце
Мясистый жгут, тёплый пурпурно-фиолетовый верх, розовато-сиреневая нижняя сторона
с рядом присосок по центру. Влажный блик вдоль одной стороны. Анимация: волна по длине —
блик и присоски смещаются на 1 px за кадр, силуэт чуть «дышит».
`head.png`: сужающийся кончик с крупной присоской-хваталкой и парой мелких крючков.

### `ghost` — призрачные цепи
Звенья из холодного бледно-голубого/белёсого света, полупрозрачные (альфа 90–190 внутри,
края мягче за счёт полупрозрачных пикселей, но **без** сглаживания — прозрачность
ступенчатая, не градиентная). Между звеньями — редкие вспышки дымки. Анимация: мерцание
и медленный «пробег» свечения вдоль цепи.
`head.png`: призрачный коготь/крюк, самый яркий пиксель — на острие.

## Пайплайн и инструменты

Повторяй то, как в репозитории уже сделаны бары боссов:

- Aseprite-исходники: `art/aseprite/hook/<id>.aseprite`, слои с осмысленными именами
  (`base`, `shading`, `highlights`, `glow`, `head`), 4 фрейма в таймлайне.
- Палитра: `art/aseprite/hook/<id>.gpl`.
- Скрипт сборки: `scripts/build_hook_cords.lua`, запускается как
  `aseprite --batch --script-param projectDir=<repo> --script scripts/build_hook_cords.lua`,
  экспортирует из `.aseprite` готовые filmstrip-PNG по путям контракта. Образцы стиля и
  структуры Lua: `art/aseprite/boss_bar/sculk/build_runtime_layers.lua` и
  `art/aseprite/boss_bar/sculk/package_runtime_layers.lua`.
- Если Aseprite CLI в системе недоступен — **не** блокируйся: сделай генерацию на
  Python + Pillow, как `scripts/generate_infernal_boss_bar.py` (там же есть готовый
  писатель `.aseprite`: функции `aseprite_layer_chunk` / `aseprite_cel_chunk` /
  `write_aseprite` / `validate_aseprite` — переиспользуй их, чтобы исходники всё равно
  открывались в Aseprite). В ответе честно напиши, каким путём пошёл.
- Превью для ревью: `art/aseprite/hook/preview/<id>_8x.png` — апскейл ×8
  **nearest neighbour**, на одном листе: 4 кадра по отдельности + вертикальная склейка
  из 8 сегментов + наконечник, всё на трёх фонах (тёмный камень, светлое небо, шахматка).

## Самопроверка перед сдачей

1. Размеры ровно 16×64, режим RGBA8 — проверить скриптом, а не глазами.
2. Склейка 8 сегментов одного кадра: шва не видно ни на одном из 4 кадров.
3. Цикл: кадр 3 → кадр 0 без скачка.
4. Количество уникальных цветов на стиль ≤ 14 (альфа-варианты `ghost` считать отдельно,
   но тоже держать в узде).
5. Нет полупрозрачных «грязных» пикселей (альфа 1–20) за пределами силуэта.
6. Пересборка из исходника скриптом даёт **побайтово те же** PNG.
